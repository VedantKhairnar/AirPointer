     python3 -m venv venv
     source venv/bin/activate  # On Windows: venv\Scripts\activate

  2. Install dependencies:
     pip install -r requirements.txt

     curl -L https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task -o hand_landmarker.task

     python test.py

  5. Start system:
     python main.py

  Controls: q=quit, d=debug, m=mouse (enable mouse control)

🎯 KEY DESIGN DECISIONS

  ✓ No Gesture Classification
    • No machine learning, no training
    • Pure rule-based temporal logic
    • Actions inferred from hand mechanics
    • Works for any hand size, speed, user

  ✓ Implicit Gesture Emergence
    • Gestures are patterns over time
    • Users don't need to "learn" gestures
    • Actions feel natural and intuitive

  ✓ Conservative Behavior
    • If unsure, do nothing
    • Prefer false negatives to false positives
    • Users never feel surprised

  ✓ Temporal Confirmation
    • Click: ≥150ms hold time
    • Drag: ≥100ms pinch duration
    • Cooldown: 200ms between actions
    • Prevents double-fires and accidental triggers

  ✓ State Machine with Priority Arbitration
    • Explicit, debuggable state transitions
    • Clear priority order prevents conflicts
    • No ambiguous decision points

🏗️  ARCHITECTURE OVERVIEW

  Pipeline (per 33ms frame):

  [Camera Input]
        ↓ (5-10ms)
  [Perception: MediaPipe Hands]
        ↓ 21 landmarks [x,y,z]
        ↓ (1-2ms)
  [Feature Extraction]
        ↓ Palm position, velocity, finger states, pinch distance
        ↓ (1-2ms)
  [Temporal Analysis: 15-frame window]
        ↓ Velocity trend, stability, pinch duration
        ↓ (1ms)
  [State Management: FSM]
        ↓ IDLE → MOVE → CLICK → DRAG → SCROLL → COOLDOWN
        ↓ (0.5-1ms)
  [Action Execution]
        ↓ OS mouse event (move, click, drag, scroll)
        ↓ (3-5ms if debug enabled)
  [Debug Visualization]
        ↓
  [System Cursor / Screen]

  Total Latency: ~50-100ms (camera → visible cursor response)

───────────────────────────────────────────────────────────────────────────────

⚙️  STATES & TRANSITIONS

  IDLE (default)
    ↓
    ├─→ MOVE: Palm moving + no finger engagement
    │   └─→ IDLE (when hand stops)
    │
    ├─→ CLICK_ENGAGED: Palm stable + deliberate finger motion (≥150ms)
    │   └─→ COOLDOWN (after click) → IDLE
    │
    ├─→ DRAG: Pinch sustained (≥100ms) + palm moving
    │   └─→ IDLE (when pinch released)
    │
    └─→ SCROLL: Vertical motion + no pinch
        └─→ IDLE (when motion stops)

  Priority (when multiple states possible):
    1. DRAG (most intentional)
    2. CLICK
    3. SCROLL
    4. MOVE (continuous)

🔧 CONFIGURATION

  Key Parameters (in config.py):

  Timing (seconds):
    CLICK_HOLD_TIME = 0.15          # Minimum hold for click confirmation
    COOLDOWN_TIME = 0.2             # Pause between discrete actions
    DRAG_MIN_TIME = 0.1             # Minimum drag duration

  Thresholds:
    VELOCITY_THRESHOLD = 0.01       # Movement detection sensitivity
    STABILITY_THRESHOLD = 0.7       # Palm stability requirement
    PINCH_THRESHOLD = 0.3           # Pinch distance threshold

  Smoothing & Quality:
    CURSOR_SMOOTHING_FACTOR = 0.6   # 0=none, 1=full
    TEMPORAL_WINDOW_SIZE = 15       # Frames in sliding window

  Screen Settings:
    SCREEN_WIDTH = 1920
    SCREEN_HEIGHT = 1080

  All parameters adjustable without code changes!
